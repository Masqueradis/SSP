# Задание 4 — Исследование статических ссылок и утечек памяти

**Файл:** `Lab2/Task4/Program.cs`
**Целевая платформа:** .NET 10.0 (SDK 10.0.401)

## Суть задания

1. Создать класс, демонстрирующий утечку через статическую коллекцию.
2. Создать класс, демонстрирующий утечку через неподписанные события.
3. Исследовать перемещение объектов между поколениями.

## Часть 1. Статическая утечка (StaticLeakDemo)

`AddData()` добавляет 1000 объектов по 10 КБ в `static List<byte[]>`;
`CheckMemory()` выводит `GC.GetTotalMemory`, количество объектов и поколение
списка.

Результат:

```
До AddData(): 9 MB, объектов 0
После AddData(): 9 MB, объектов 1 000,  поколение 2
После GC.Collect()+WaitForPendingFinalizers(): по-прежнему 9 MB, 1 000 объектов
После Reset() + GC.Collect(): 0 MB, объектов 0
```

**Объяснение:** статическая коллекция — корень GC. Пока в ней есть ссылки,
объекты не могут быть собраны, даже если на них нигде больше нет ссылок.
Только очистка списка (`Reset()`) делает объекты недостижимыми.

## Часть 2. Событийная утечка (EventLeakDemo)

100 подписчиков по 256 КБ, подписанных на событие `DataEvent`.

```
Память после 100 подписок: 25 MB, Working Set 39 MB
Память после отписки всех: 0 MB
```

**Вопросы и ответы:**

- *Почему объекты в обработчике события не удаляются?* Событие — это поле-
  делегат издателя; делегат хранит ссылку на обработчик (объект-подписчик).
  Пока подписка существует, подписчик достижим из корня и не собирается GC.
- *Что происходит с памятью после отписки?* Ссылка разрывается; если других
  ссылок нет, при следующем `GC.Collect()` объекты-подписчики удаляются.

## Часть 3. Сравнение поколений объектов

```
Объект сразу после создания: поколение 0
После GC.Collect() #1: поколение 1
После GC.Collect() #2: поколение 2
После GC.Collect() #3: поколение 2

10 КБ  -> поколение 0 (SOH)
50 КБ  -> поколение 0 (SOH)
90 КБ  -> поколение 2 (LOH)   размер > 85 КБ
200 КБ -> поколение 2 (LOH)   размер > 85 КБ
```

**Ожидаемый результат подтверждён:** объекты перемещаются Gen0 → Gen1 → Gen2,
объекты > 85 КБ сразу попадают в LOH (Gen2) и не уплотняются.
