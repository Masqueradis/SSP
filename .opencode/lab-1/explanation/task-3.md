# Задание 3 — Создание динамического метода

**Файл:** `Lab1/Task3/Program.cs`
**Целевая платформа:** .NET 8.0

## Суть задания

3.1 Создать динамический метод для нахождения **максимума из трёх чисел** (п. 2.2).
3.2 Создать динамический метод для нахождения **абсолютной величины вещественного числа**.

Методы создаются в рантайме: `CreateMax()` (тот же алгоритм, что в задании 2) и
`CreateAbs()` — модуль реализован «вручную» без вызова `Math.Abs`.

## 3.1 Максимум из трёх чисел (`CreateMax`)

Динамический метод `Max` с сигнатурой `(int, int, int) → int`:
`max = a`; `if (max < b) max = b`; `if (max < c) max = c`; `return max`.

Локальная переменная `max` (`stloc.0`), метки `b`, `c`, `end` и условные переходы
`blt`, безусловный `br`.

### Результат

```
Max(3, 7, 5)    = 7
Max(10, 2, 4)   = 10
Max(-3, -1, -2) = -1
```

## 3.2 Модуль вещественного числа (`CreateAbs`)

Сигнатура `(double) → double`. Эквивалент C#:

```csharp
double Abs(double x)
{
    if (x < 0) return -x;
    return x;
}
```

IL:

```
ldarg.0
ldc.r8 0.0        // загрузить константу 0.0
blt    neg        // если x < 0 → neg
ldarg.0
ret               // иначе вернуть x

neg: ldarg.0
     neg          // -x
     ret
```

Здесь показаны `ldc.r8` (загрузка 64-битной вещественной константы), условный
переход `blt` для `double` и инструкция смены знака `neg`.

### Результат

```
Abs(5.5)   = 5.5
Abs(-7.25) = 7.25
Abs(0.0)   = 0
Abs(-3.14) = 3.14
```

## Вывод

`DynamicMethod` позволяет создавать методы «на лету»: задаются сигнатура и модуль,
тело заполняется `ILGenerator` (ветвления, локальные переменные, арифметика), а
готовый метод превращается в типизированный делегат.
