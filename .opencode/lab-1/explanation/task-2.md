# Шпоргалка: IL-инструкции из Task2

## Загрузка аргументов метода (параметры)

| Инструкция | Байт | Описание | Стек до → стек после |
|---|---|---|---|
| `Ldarg_0` | `0x02` | Загрузить параметр #0 (первый аргумент) | → [arg0] |
| `Ldarg_1` | `0x03` | Загрузить параметр #1 (второй аргумент) | → [arg1] |
| `Ldarg_2` | `0x04` | Загрузить параметр #2 (третий аргумент) | → [arg2] |

## Загрузка локальных переменных

| Инструкция | Байт | Описание | Стек до → стек после |
|---|---|---|---|
| `Ldloc_0` | `0x06` | Загрузить локальную переменную #0 на стек | → [loc0] |

## Сохранение со стека в локальную переменную

| Инструкция | Байт | Описание | Стек до → стек после |
|---|---|---|---|
| `Stloc_0` | `0x0A` | Снять верхний элемент стека → сохранить в loc0 | [val] → [] |

## Загрузка констант

| Инструкция | Байт | Описание | Стек до → стек после |
|---|---|---|---|
| `Ldc_I4_1` | `0x16` | Загрузить целое число 1 на стек | → [1] |

## Арифметика

| Инструкция | Байт | Описание | Стек до → стек после |
|---|---|---|---|
| `Add` | `0x58` | Сложить два верхних элемента | [a, b] → [a+b] |
| `Sub` | `0x5B` | Вычесть: предпоследний минус последний | [a, b] → [a−b] |
| `Mul` | `0x5A` | Перемножить два верхних элемента | [a, b] → [a×b] |

## Ветвления (условные переходы)

| Инструкция | Байт | Описание | Стек до → стек после |
|---|---|---|---|
| `Blt` | `0x3D` | Branch if Less Than — переход если предпоследний < последний | [a, b] → [] |
| `Ble` | `0x3E` | Branch if Less or Equal — переход если предпоследний ≤ последний | [a, b] → [] |
| `Br` | `0x38` | Безусловный переход к метке | [] → [] |

## Вызов метода и возврат

| Инструкция | Байт | Описание | Стек до → стек после |
|---|---|---|---|
| `Call` | `0x28` | Вызвать метод (аргументы снимаются со стека) | [args...] → [result] |
| `Ret` | `0x2A` | Вернуть значение с вершины стека как результат | [result] → [] |

---

## Мнемоника запоминается так

| Префикс/часть | Значение |
|---|---|
| `ld` | **LoaD** — загрузить на стек |
| `st` | **STore** — сохранить со стека |
| `arg` | **ARG**ument — аргумент метода |
| `loc` | **LOC**al — локальная переменная |
| `c` / `i4` | **C**onstant, **I**nteger **4** байта (int32) |
| `ret` | **RET**urn — возврат |
| `b` | **B**ranch — переход |
| `l` / `lt` | **L**ess **T**han — меньше |
| `le` | **L**ess or **E**qual — меньше или равно |

## Пример: Max(3, 7, 5)

```asm
Ldarg_0       ; загрузить a=3          стек: [3]
Stloc_0       ; max = 3                стек: []

Ldloc_0       ; загрузить max=3        стек: [3]
Ldarg_1       ; загрузить b=7          стек: [3, 7]
Blt    b      ; 3 < 7? ДА → goto b    стек: []

Ldloc_0       ; (если нет) max         стек: [max]
Ldarg_2       ; загрузить c            стек: [max, c]
Blt    c      ; max < c?               стек: []
Br     end    ; goto end

b:            ; max оказался < b
Ldarg_1       ; загрузить b            стек: [b]
Stloc_0       ; max = b                стек: []

Ldloc_0       ; загрузить max          стек: [max]
Ldarg_2       ; загрузить c            стек: [max, c]
Blt    c      ; max < c?               стек: []
Br     end

c:            ; c — самый большой
Ldarg_2       ; загрузить c            стек: [c]
Stloc_0       ; max = c                стек: []

end:
Ldloc_0       ; загрузить результат    стек: [result]
Ret           ; return result          стек: []
```
