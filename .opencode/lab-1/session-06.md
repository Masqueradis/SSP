# Сессия 06 — Удаление пояснений и комментариев из вывода

## Дата
07.09.2026

## Задача
Убрать комментарии в коде и поясняющий текст при выводе программ.

## Выполненные изменения

### Task1 (`Lab1/Task1/Program.cs`)
- Удалены текстовые пояснения после вывода IL:
  - «Expression-bodied: 0 локальных, 4 инструкции...»
  - «Блочное тело: 2 локальные, 11 инструкций...»
  - «nop и br.s — отладочный шум...»
- В методе `Trace` удалена поясняющая колонка «Операция» с описаниями на русском языке («загрузить a», «умножить» и т.д.).
- Таблица трассировки теперь содержит только: `Адрес │ HEX │ Мнемоника │ Стек`.

### Task5 (`Lab1/Task5/Program.cs`)
- Аналогично удалена колонка «Операция» с описаниями из метода `Trace`.
- Удалён параметр `method` из `Trace` (имена параметров больше не подставляются в колонку).
- Сигнатура: `Trace(byte[] il, MethodBody body)`.

### Task2, Task3, Task4
- Просмотрены: в коде нет комментариев, пояснительный текст при выводе отсутствует. Изменения не требовались.
