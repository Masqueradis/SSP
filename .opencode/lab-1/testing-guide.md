# Testing Guide — Лабораторная работа 1

**Тема:** Платформа .NET: Анализ IL-кода и JIT-компиляции

Пошаговая инструкция по запуску, демонстрации и сдаче лабораторной работы преподавателю.

Выполнено на **.NET 8.0** (SDK 8.0.130). Проекты находятся в `Lab1/Task1` … `Lab1/Task5`.
В каждом задании один файл `Program.cs`.

---

## 0. Требования к окружению

- .NET SDK **8.0** (проверить: `dotnet --version`).
- Инструменты `ildasm` / `ilasm` — при необходимости анализа IL вне программы.

---

## 1. Задание 1 — Анализ IL-кода

**Запуск:** `cd Lab1/Task1 && dotnet run`

**Ожидаемый результат:**
```
6 * 8 = 48

IL: 02 03 5A 2A
Размер IL: 4 байт
Локальные переменные: 0
Максимальный размер стека: 8
```

**Объяснение для преподавателя:** `02`=ldarg.0, `03`=ldarg.1, `5A`=mul, `2A`=ret.
`Multiply(a, b) => a * b` — 4 однобайтовые IL-инструкции без локальных переменных.

## 2. Задание 2 — Работа с IL-генератором

**Запуск:** `cd Lab1/Task2 && dotnet run`

**Ожидаемый результат:**
```
0! = 1 ... 7! = 5040
Max(3, 7, 5)    = 7
Max(-1, -5, -2) = -1
Max(9, 2, 9)    = 9
```

**Демонстрация:** методы созданы в рантайме через `DynamicMethod` + `ILGenerator`.
Рекурсия факториала — `Emit(OpCodes.Call, m)` вызывает сам создаваемый метод.

## 3. Задание 3 — Создание динамического метода

**Запуск:** `cd Lab1/Task3 && dotnet run`

**Ожидаемый результат:**
```
Max(3, 7, 5)    = 7
Max(10, 2, 4)   = 10
Max(-3, -1, -2) = -1

Abs(5.5)   = 5.5
Abs(-7.25) = 7.25
Abs(0.0)   = 0
Abs(-3.14) = 3.14
```

**Демонстрация:** модуль реализован без `Math.Abs` через `ldc.r8`, `blt`, `neg`.

## 4. Задание 4 — Исследование JIT-компиляции

**Запуск:** `cd Lab1/Task4 && dotnet run`

**Ожидаемый результат (значения могут немного отличаться):**
```
Первый вызов (JIT): ~280 мкс
100000 вызовов после компиляции: ~2500 мс  (~25 мкс на вызов)
200 новых DynamicMethod (каждый со своим JIT): ~19 мс  (~100 мкс на создание)
```

**Объяснение:** первый вызов включает однократную JIT-компиляцию (~280 мкс),
«тёплые» вызовы идут из скомпилированного кода (~25 мкс). Массив — 10000 целых
чисел.

## 5. Задание 5 — Профилирование и оптимизация

**Запуск:** `cd Lab1/Task5 && dotnet run`

**Ожидаемый результат:**
```
Адрес метода Add: 0x...16
Размер IL: 4 байт
Локальные переменные: 0
Максимальный стек: 8

10,000,000 итераций:
  Прямой вызов:         24 мс
  Статический метод:    53 мс
  Делегат:              54 мс
  Виртуальный метод:    55 мс
```

**Объяснение для преподавателя:** `PrepareMethod` + `GetFunctionPointer()` —
адрес скомпилированного кода. Прямой вызов быстрее всех, т. к. JIT инлайнит код;
делегат и виртуальный вызов имеют накладные расходы диспетчеризации.
