# Задание 6 — CancellationToken (отмена операций)

**Проект:** `Lab5/Task6` · **Запуск:** `cd Lab5/Task6 && dotnet run`
**Источник:** `МногопотАинхПрогр.docx`, задание 6

## Что делает программа

Пять сценариев кооперативной отмены: таймаут, ручная отмена, прерывание
долгой работы, объединение источников и проверка токена без исключений.

### Часть 6.1. CancelAfter: отмена по таймауту

Работа делает шаги по 300 мс, источник настроен на отмену через 1 секунду.
Работа останавливается между шагами, а не посреди `Thread.Sleep`:

```
Шаг 1 выполнен · Шаг 2 выполнен · Шаг 3 выполнен
Операция отменена через 1000 мс
```

Это ключевая идея кооперативной отмены: токен не прерывает код сам, а даёт
ему **шанс остановиться** в безопасной точке.

### Часть 6.2. Ручная отмена

Работа запускается, затем через 800 мс вызывается `cts.Cancel()`. Работа
завершается досрочно, в обработчике отмены печатается подтверждение
`IsCancellationRequested = True`.

### Часть 6.3. Прерывание долгого цикла

Цикл из 100 000 шагов с проверкой токена каждые 1000 итераций. Отмена на
10-й итерации приводит к «мягкой остановке»; программа печатает, сколько
элементов обработано, и показывает, что цикл прервался, а не откатился.

### Часть 6.4. CreateLinkedTokenSource

Объединение нескольких источников в один токен:

* **Случай A** — объединены таймаут 2 с и ручной источник, ждём таймаут:
  ```
  Операция отменена через 2000 мс, сработал: таймаут
  timeout.IsCancellationRequested = True, manual.IsCancellationRequested = False, linked = True
  ```
* **Случай B** — объединён только ручной источник, отменён через 1 секунду:
  ```
  Операция отменена через 1001 мс, сработала ручная отмена
  linked.IsCancellationRequested = True, всего обработчиков отмены: 1
  ```

Вывод: общий токен отменяется при отмене любого из источников.

### Часть 6.5. Проверка без исключений

`token.IsCancellationRequested` **не бросает** `OperationCanceledException` —
в отличие от `ThrowIfCancellationRequested`. В примере цикл прерывается
мягко: `Цикл мягко остановлен на итерации 10, обработано 10 элементов`.

## Ключевые выводы

1. Отмена кооперативная: код сам решает, где остановиться.
2. Проверяйте токен часто, но **не внутри** горячего цикла на каждой итерации —
   это сопоставимо по цене с самой работой.
3. `CreateLinkedTokenSource` объединяет источники; отмена любого гасит общий токен.
4. `IsCancellationRequested` — безопасная проверка, `ThrowIfCancellationRequested` —
   способ выйти из метода с исключением, которое вызывающий код поймает как ожидаемое.
5. `linked.Dispose()` обязателен: он освобождает регистрации в исходных источниках.
